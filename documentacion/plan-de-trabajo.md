# Plan de Trabajo

## Proyecto
Control Financiero para Microempresarios

## Responsable
Andreina De Leon Ramirez

## Objetivo del plan
Definir las tareas iniciales del proyecto y la forma en que se
organizaran, para dejar evidencia de una correcta gestion de
configuracion desde el inicio.

## Tareas iniciales
1. Crear estructura inicial del proyecto (etiqueta: enhancement)
2. Completar archivo README.md (etiqueta: documentation)
3. Revisar organizacion de carpetas (etiqueta: documentation)
4. Preparar primera version del proyecto (etiqueta: enhancement)
5. Documentar el plan de trabajo (etiqueta: documentation)

## Estados del tablero
- **Pendiente:** tarea registrada, aun sin iniciar.
- **En proceso:** tarea en desarrollo.
- **En revision:** tarea terminada, pendiente de verificar.
- **Completado:** tarea verificada y finalizada.

## Control de versiones
- Cada avance se guardara en un commit con un mensaje claro y
  relacionado con el cambio realizado.
- Los cambios se subiran al repositorio de GitHub con cada commit.
