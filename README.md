# Control Financiero para Microempresarios

## Descripción breve del proyecto
Prototipo de una herramienta sencilla para que microempresarios registren y controlen sus ingresos y gastos diarios, y puedan visualizar de forma clara el balance de su negocio. Está inspirado en necesidades reales de pequeños emprendedores que hoy llevan estas cuentas de forma manual o desorganizada.

## Objetivo del proyecto
Facilitar el control financiero básico de un microempresario mediante una interfaz simple donde pueda registrar movimientos de dinero (ingresos y gastos) y consultar su balance actualizado, sin necesidad de conocimientos contables avanzados.

## Herramientas utilizadas
- Git y GitHub para control de versiones
- GitHub Desktop para gestión de commits
- GitHub Issues para el registro de tareas
- GitHub Projects para el tablero Kanban
- Visual Studio Code para edición de archivos
- Markdown para la documentación
